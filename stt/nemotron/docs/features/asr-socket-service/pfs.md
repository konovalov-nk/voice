# PFS: ASR Microphone Socket Service

- **Level**: product
- **Status**: draft
- **Author**: user + agent

## Goal

Непрерывно слушать микрофон (Pipewire node) через ASR (Nemotron 3.5) и отдавать распознанный текст потребителям через Unix socket.

## Stories

- As a **пользователь**, I can запустить сервис и он сразу начинает слушать мой дефолтный микрофон, чтобы я видел распознанную речь.
- As a **пользователь**, I can подключиться к Unix socket и читать распознанный текст строчка за строчкой, чтобы использовать его в других приложениях (zellij, копирование, OBS, стримы).
- As a **пользователь**, I can указать язык распознавания (en-US, ru-RU, auto), и сервис будет детектить/транскрайбить на этом языке.
- As a **пользователь**, I can остановить сервис (Ctrl+C) и он корректно завершит захват аудио и закроет сокет.

## Acceptance Criteria

1. **Given** сервис запущен, **When** я говорю в микрофон, **Then** распознанный текст появляется в подключенных клиентах с задержкой не более ~2сек.
2. **Given** сервис запущен, **When** я подключаюсь к Unix socket через `nc -U /tmp/asr.sock`, **Then** я получаю все новые распознанные строки по мере их появления.
3. **Given** сервис работает и клиент подключен, **When** клиент отключается, **Then** сервис продолжает работать без падения.
4. **Given** сервис работает и микрофон молчит, **Then** сервис не пишет мусор (пустые/шумовые гипотезы отбрасываются VAD или энергетическим порогом).
5. **Given** сервис запущен с `--lang ru-RU`, **When** я говорю по-русски, **Then** распознавание работает на русском.
6. **Given** сервис запущен, **When** я нажимаю Ctrl+C, **Then** Pipewire стрим закрывается, сокет удаляется, процесс завершается с кодом 0.

## Non-goals

- Хранение истории распознавания (log-файл) — НЕ входит в PFS (будет в TFS, если нужно)
- Сохранение аудио в файл
- GUI-интерфейс
- Поддержка нескольких микрофонов одновременно
- Синтез речи (TTS)
- Кластеризация спикеров (diarization)
